# 两篇学生碳足迹论文解析

这两篇都在算中国大学生的个人碳足迹，但边界和问题不一样。

- 李等（2015）算的是同济学生在校期间能被行为改变的运行排放。
- 朱等（2026）算的是北大学生生活方式消费（校园范围三），并进一步解释“想低碳却做不到”，再估干预能减多少。

数字不能直接对比。3.84 t 和 2.54 t 差在边界和年份：同济算的是 2009–2010 年的在校运行排放（食堂运营、淋浴、宿舍电、学习分摊），明确不含上游；北大算的是近年生活方式消费，食物生产碳排进了账，所以食物接近一半。

## 1. 李等（2015）：同济学生行为碳足迹

- 题名：Carbon footprint analysis of student behavior for a sustainable university campus in China
- 作者：Xiwang Li, Hongwei Tan, Adams Rackes
- 期刊：Journal of Cleaner Production, 106 (2015) 97–108
- 案例：上海同济大学
- 数据：2009–2010 年在线问卷。约 2.1 万封邮件，回复率约 5%，1029 份回复、923 份可用，叠加上建筑能耗监测和排放因子。

样本构成：男 637、女 286；本科 507、硕士 337、博士 79；农村 133、小镇 277、大城市 513。学位和家乡分布接近全校，但男性比例偏高。

### 1.1 算什么

他们定义的是“个人运行阶段碳足迹”：吃饭、洗澡、宿舍用电、学习、通勤和出行。不包括食物和商品的上游生产，也不包括废弃物处理。一年按九个月在校折算。

活动排放大致是排放因子乘活动量，例如每餐、每次淋浴、每公里。学习空间则按建筑逐时能耗，再除以设计人数和自报上座率，分摊到个人。食堂吃饭、校外吃饭、娱乐用电脑、饮用热水等是可加总的；主要学习地点、日常通勤方式、回老家的交通方式互斥，只取学生填的主要方式。

部分排放因子（华东电网，电 0.79 kgCO₂e/kWh）：

| 活动 | 因子 |
|---|---|
| 食堂就餐 | 0.73 kgCO₂e/餐 |
| 校外餐馆 | 1.21 kgCO₂e/餐 |
| 电脑（娱乐或学习） | 0.079 kgCO₂e/小时 |
| 饮用热水 | 0.41 kgCO₂e/小时 |
| 打印 | 0.0043 kgCO₂e/页 |
| 班车 / 火车 / 私家车 | 0.029 / 0.068 / 0.27 kgCO₂e/km |
| 自行车 | 0 |

### 1.2 结果

人均每年 **3.84 tCO₂e**（标准差 1.01）。低于作者引用的中国大学生整体估计 4.1 t，也低于挪威科技大学学生估计 4.6 t。正文把偏低归因于同济已经采取的一些节能措施；结论则强调，偏低很大程度上是因为当时宿舍没有空调、热水和私密淋浴不足，是用舒适性换来的，不是设备已经很高效。

| 大类 | 占比 | 主要来源 |
|---|---|---|
| 日常生活 | 65%（约 2.50 t） | 餐饮 1.24 t（34%）、淋浴 0.65 t（18%）、宿舍插座负荷 0.50 t（14%） |
| 交通 | 20%（约 0.77 t） | 回老家约一半，日常通勤约三分之一，度假约五分之一 |
| 学业 | 15%（约 0.58 t） | 学习用电脑、打印扫描；图书馆和教室的能耗分摊很少 |

前十项活动（人均 tCO₂e，占总量）：

| 活动 | tCO₂e | 占比 |
|---|---|---|
| 餐饮 | 1.24 | 33.80% |
| 淋浴 | 0.65 | 17.66% |
| 宿舍插座负荷 | 0.50 | 13.65% |
| 回老家 | 0.36 | 9.80% |
| 学习用电脑 | 0.24 | 6.60% |
| 日常通勤 | 0.24 | 6.60% |
| 打印和扫描 | 0.17 | 4.65% |
| 度假出行 | 0.14 | 3.80% |
| 图书馆学习分摊 | 0.06 | 1.65% |
| 教室学习分摊 | 0.04 | 1.05% |

和墨西哥、英国校园比，同济交通占比低（对方通勤往往占交通排放的约 90%），因为多数学生住校、步行。同济交通排放里约 50% 是回老家，32% 是日常通勤。

### 1.3 谁更高

| 群体 | 日常生活 | 学业 | 交通 | 合计 |
|---|---|---|---|---|
| 男 | 2.61 | 0.64 | 0.83 | 4.08 |
| 女 | 2.24 | 0.43 | 0.62 | 3.29 |
| 本科 | 2.40 | 0.54 | 0.61 | 3.55 |
| 硕士 | 2.58 | 0.61 | 1.01 | 4.20 |
| 博士 | 2.80 | 0.70 | 0.74 | 4.24 |
| 农村 | 2.30 | 0.32 | 0.63 | 3.13 |
| 小镇 | 2.09 | 0.63 | 0.86 | 3.31 |
| 大城市 | 2.47 | 0.45 | 1.33 | 3.84 |

单位：tCO₂e/人·年。

原因很具体：

- 男生更常在校外吃饭（男 55% 校外、45% 食堂；女 33% 校外、67% 食堂），也更常在宿舍学习（男 60% 宿舍、40% 图书馆；女 20% 宿舍、80% 图书馆）。男生度假出行距离更长。
- 学历越高，住宿越不密集。本科常见四人间，硕士两到三人，博士常常单住。博士多在三四人的个人办公室学习；硕士办公室常常十到二十人；约一半本科生主要在图书馆学习，人均能耗更低。硕士交通最高，是因为度假距离更长。
- 来自大城市的学生多数就是上海及郊区：回家近、往返勤，很多人住家里，通勤碳排高。外地学生更常住宿舍、周末留校，足迹更像“短距离、高密度”的城市生活。

### 1.4 能减的行为

- 在校吃饭相对全在外面吃，大约差 0.4 t，约人均足迹的 10%。校外餐馆每餐温室气体大约比食堂高 80%（因子 1.21 对 0.73；按差值计算约为 66%，论文正文写的是约 80%）。
- 集中浴室用热泵、锅炉和太阳能，大约只有宿舍电热水器的三分之一（按每天一次淋浴）。
- 宿舍电热水器若从常开改为用前一小时再开：常开 0.78 t，用前再开 0.46 t，当前平均 0.65 t。相对当前可少 0.19 t，约总量的 5%。
- 图书馆或教室上座率 20% 时，人均比上座率 80% 高约 75%，大约多 0.05 t。人越多，公共空间人均越低。
- 离开宿舍会规律关掉电脑和灯的只有 22%；离开超过 1 小时会关的有 53%。87% 的人觉得自己在节能。作者估计，热水器使用习惯加上学习地点的改变，合计可以超过 0.2 t。打印扫描只占约 5%，减的空间不大。

### 1.5 校园升级情景

如果以后人人宿舍淋浴、宿舍和教室都装空调：

| 改进 | 方案 | tCO₂e/人 |
|---|---|---|
| 淋浴（当前混合） | — | 0.65 |
| 宿舍独立淋浴 | 1a 每间电热水器 | 1.89 |
| 宿舍独立淋浴 | 1b 楼宇集中太阳能 + 电辅热 | 0.56 |
| 宿舍独立淋浴 | 1c 校园区域热水 | 1.24 |
| 宿舍热舒适（当前无空调） | 2a 分体空调 | 1.16 |
| 宿舍热舒适 | 2b 集中空调 | 0.86 |
| 教室热舒适（当前无空调） | 3a 分体空调 | 0.66 |
| 教室热舒适 | 3b 集中空调 | 0.46 |

| 类别 | 当前 | 可持续改进（1b+2b+3b） | 不可持续改进（1a+2a+3a） |
|---|---|---|---|
| 日常生活 | 2.50 | 3.27 | 4.90 |
| 学业 | 0.58 | 1.04 | 1.24 |
| 交通 | 0.77 | 不变 | 不变 |
| 合计 | 3.84 | 5.08（+32%） | 6.91（+80%） |

集中太阳能热水甚至可以比现在的混合淋浴略低。集中空调比分体空调的碳成本更低，但相对“现在没有空调”仍然是净增加。作者还建议：把食堂做得更好以把学生留在校内；校园继续可步行、靠近公交、自己提供购物和娱乐，避免学生为这些出行；图书馆存在夏季过冷（超过 60% 觉得冷或太冷）、冬季过热（超过 20% 觉得热），属于浪费，调设定温度即可。

### 1.6 局限

只含运行阶段，不含上游生产和下游废弃物。受访者男性比例高于全校。未来工作是提高女生回复率，并把隐含排放算进去。

## 2. 朱等（2026）：从意愿到行为

- 题名：From intention to action: Modeling student lifestyle carbon emissions and reduction scenarios
- 作者：Weiwang Zhu, Dihua Li, Wei Liu（北京大学建筑与景观设计学院；IIASA）
- 期刊：Cleaner and Responsible Consumption, 21 (2026) 100391
- 案例：北京大学燕园主校区及长春园、中关新园、万柳公寓、圆明园周边学生住区
- 数据：410 份有效问卷

样本：男 45.9%、女 54.1%；本科 45.4%、硕士 42.9%、博士 11.7%。月消费 2001–3000 元占 34.4%，1001–2000 元占 29.3%。四人合住占 59.0%。截至 2021 年底，校园师生 58831 人，其中学生 46148 人。

三个研究问题：

1. 校园范围三边界内，学生生活方式碳排放的量和结构是什么？
2. 在 TPB、VBN、CADM 整合框架下，低碳意愿能在多大程度上变成实际行为？如果有意愿—行动偏差，关键约束是什么？
3. 在避免—转移—改进（Avoid–Shift–Improve）框架下，两种干预逻辑能减多少，哪类杠杆贡献最大？

### 2.1 算什么

边界是校园范围三里的生活方式：衣、食、住、行、日用和垃圾，对应学生差旅、通勤、校园生活垃圾、以及与学习相关的采购消费。算法是 IPCC 的活动量乘排放因子。因子来自 IPCC 国家清单指南、中国省级清单指南、北京企业二氧化碳核算指南，以及中国产品全生命周期温室气体系数。

这和李文不同：食物生产的碳排进了账，所以食物份额会高得多。

### 2.2 碳足迹结果

人均每年 **2535.53 kgCO₂e（约 2.54 t）**。

| 来源 | 占比 |
|---|---|
| 食物 | 47.36% |
| 交通 | 24.05% |
| 日常用电 | 17% |

高排放行为集中在外卖、高肉饮食、出差和网约车。

- 77.7% 的人自称偏好低碳出行，但 68% 每周网约车或出租车超过 1 小时。
- 近 40% 的人不到一半的饭在食堂吃。
- 外卖相关年排放高达 485.85 kg。
- 只有 16.3% 经常光盘。
- 饮食结构在从东方模式转向高肉、高能量、高脂肪、高蛋白、低纤维。

月消费每多 1000 元，年人均排放大约高 12.76%（Kruskal–Wallis 及事后比较）。性别差异主要在饮食和衣着；硕士交通排放更高，和住的位置有关。

### 2.3 为什么做不到

他们把三套理论放进同一个结构方程模型，而不是只用一个理论解释“高意愿、低行动”：

- 计划行为理论（TPB）：态度、主观规范、感知行为控制决定意愿；感知控制还可以直接影响行为。解释“能不能做到”。
- 价值—信念—规范理论（VBN）：生态价值 → 责任归属 → 个人规范 → 意愿。解释“应不应该做”。
- 综合行动决定模型（CADM）：在上面之外加入习惯和情境。习惯和外部条件可以直接左右行为，并削弱意愿到行动的转化。

问卷为李克特 5 点量表，11 个构念、35 个题项。整体 Cronbach’s α = 0.922，KMO = 0.916。验证性因子分析拟合：χ²/df = 2.270，GFI = 0.844，RMSEA = 0.056，CFI = 0.877。维度多、结构复杂，作者认为仍可接受。题项均值从习惯 HB2 的 3.26 到生态价值 BV1 的 4.46，整体高于中点，说明态度偏环保。但个人规范明显低于“知道并同意”，习惯得分最低。行为意愿的均值甚至低于自报的低碳行为，说明有些行为靠情境推着走，不是靠意愿。

20 条假设里，和行动最相关的路径（表中为非标准化系数 / 标准化系数）：

| 路径 | 非标准化 | 标准化 | 是否成立 |
|---|---|---|---|
| 行为意愿 → 低碳行为 | 0.398 | 0.631 | 成立 |
| 感知行为控制 → 低碳行为 | 0.406 | 0.479 | 成立 |
| 情境因素 → 低碳行为 | 0.158 | 0.183 | 成立 |
| 个人规范 → 行为意愿 | 0.825 | 0.561 | 成立 |
| 情境因素 → 行为意愿 | 0.648 | 0.492 | 成立 |
| 感知行为控制 → 行为意愿 | 0.333 | 0.258 | 成立 |
| 习惯 → 行为意愿 | −0.791 | −0.770 | 成立（抑制） |
| 社会规范 → 感知行为控制 | 0.692 | 0.608 | 成立 |
| 情境因素 → 社会规范 | 0.281 | 0.865 | 成立 |
| 低碳知识 → 价值观 | 0.467 | 0.503 | 成立 |

四条不成立，这是全文最有用的部分：

- 责任归属 → 个人规范不成立。学生把减排看成政府或学校的责任，责任感内化不成个人规范。
- 态度 → 意愿不成立。控制住个人规范、情境和能力之后，正面态度本身抬不高意愿。
- 社会规范 → 意愿不成立（直接路径）。社会规范要绕道态度、感知行为控制和个人规范，再影响意愿。
- 感知行为控制 → 习惯不成立。短期内觉得“我做得到”，改不了饮食和出行上已经形成的惯性。

所以缺口主要在“意愿怎么变成行动”，不是再讲一遍气候知识。只做态度宣传过不了大约 30% 的减排门槛；要把规范内化、把行动变容易（默认选项、价格、设施），才到得了上限。

### 2.4 四个减排情景

情景是 2×2：影响来自内部还是外部，行为是被动还是主动。措施按避免（少需求）、转移（换方式）、改进（降低单位强度）分类，并计入反弹（替换消费可能把碳排加回去）。重点领域是交通、食物、居住、日用品，以及垃圾分类。

| 情景 | 含义 | 人均年排放 | 相对基线 2536 kg |
|---|---|---|---|
| 内在·被动（I–P） | 课程、信息传播，满足基本和自尊需要，触发被动改变 | 2110 kg | −13.53% |
| 外在·被动（E–P） | 在内部影响之外，用更方便的设施、规定和校园活动慢慢改选择 | 2036 kg | −16.56% |
| 内在·主动（I–A） | 学生清楚影响，主动改生活习惯 | 1769 kg | −27.50% |
| 外在·主动（E–A） | 外部条件主动把学生卷进碳中和行动，改变习惯和偏好 | 1459 kg | −40.23% |

按在校生规模，大约每年少 1.56 万到 4.64 万 tCO₂e。

分部门：

- 食物绝对减排最大，因为基线份额最高（47%）。主要来自降低肉类和外卖强度、用豆类或植物蛋白替代、优先堂食和可重复包装。
- 交通第二，对外在条件最敏感（站点可达性、便利、价格）。主动情景里，步行、骑行和公交替代明显增强。
- 居住能耗和日用品下降较温和，主要靠家电能效和节电，改进类措施边际收益有限。

作者因此建议把避免和转移（饮食结构、出行方式）放在改进（能效）前面。具体抓手包括：食堂碳标签、默认植物餐或半份、可重复包装押金、堂食或自取折扣；停车收费和公交优先报销；宿舍能耗看板、出行积分、食堂反浪费称重和反馈。学校层面可以做年度碳报告、内部碳价、绿电采购和差旅碳核算。态度宣传要和这些选择架构一起用，单做宣传关不上执行缺口。

### 2.5 局限

问卷是横截面，因果识别有限。情景里的采用率、替代系数和反弹是参数化的，对人群和时间敏感。只有一所大学，校园形态、供餐和交通供给不好直接外推。习惯的抑制作用意味着一次性行动容易回到默认轨迹，需要持续反馈和制度约束。

## 3. 两篇怎么一起用

| | 李等 2015，同济 | 朱等 2026，北大 |
|---|---|---|
| 问题 | 行为相关排放在哪，改行为或升级设施各是多少吨 | 生活方式排放是多少，意愿为什么变不成行动，干预上限是多少 |
| 边界 | 运行阶段：食堂运营、淋浴、宿舍电、学习分摊、出行。不含上游和废弃物 | 范围三生活方式：食物生产、衣食住行、日用、垃圾 |
| 时间 | 问卷 2009–2010 | 2026 年发表，校园人数引用到 2021 年底 |
| 人均 | 3.84 tCO₂e/年 | 2.54 tCO₂e/年 |
| 最大来源 | 餐饮 34%、淋浴 18%、宿舍插座 14% | 食物 47%、交通 24%、日常用电 17% |
| 方法 | 排放因子 × 活动量，加建筑逐时分摊 | 排放因子 × 活动量，加 SEM，加 ASI 情景 |
| 样本 | 923 份可用 | 410 份有效 |
| 行为结论 | 食堂、集中浴室、关掉热水器、在人多的地方学习，合计可超过 0.2 t；宣传和自认节能之间有缺口（87% 说自己节能，22% 会关电器） | 态度和知识已经不低；习惯压制意愿（标准化 −0.77）；外在主动干预最多约 −40%，只做认知大约 −14% 到 −28% |

两边一致的判断是：食堂优于外卖和校外餐馆，集中设施优于每人一套，住校、步行、公交优于开车。

分工可以这样理解：李文告诉你排放在哪、改哪一项大概多少吨；朱文告诉你为什么知道了还不改。习惯和情境比态度更硬，单靠宣传大约只能减一成多，设施、默认选项和价格一起上，可以到四成左右。

若要做学生碳足迹计算器，李文适合做“在校运行”分项（餐次、淋浴地点、宿舍电费、学习地点、通勤方式）和人口学对照；朱文适合做“消费侧”分项（肉菜比、外卖比例、网约车时长、月消费），以及结果页上“为什么减不动、校园可以改什么默认选项”的解释，而不是只给一个总分。
